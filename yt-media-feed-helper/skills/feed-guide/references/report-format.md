# Report format (validated by `report_save`)

The report is written in the **language of the user's question** (headings, prose, table labels). Quotes stay verbatim in
the original language; a quote in a different language than the report gets a translation into the report language on the
next line. Pass the language as `report_save(..., language="<ISO 639-1>")` (default `en`).

Every H2 heading is followed on the next line by an invisible marker `<!-- section:KEY -->`. The validator identifies
sections by this marker (reports without markers fall back to matching English/Polish heading keywords). Example in English:

```markdown
# <Title>

## TL;DR
<!-- section:tldr -->
- A bullet with a claim [[yt:v:abc12345678@125]].

## Key findings
<!-- section:findings -->
Optional cross-source findings [[yt:v:…]].

## Official information
<!-- section:official -->
Channels with communication ∈ {Official, Community Manager} and Steam community announcements.
A comment by the channel owner / CM = official information, marked "(channel owner's comment)" [[yt:c:Ugx…]].

## Semi-official information
<!-- section:semi_official -->
Media partners (early access, sponsorship) [[yt:v:…]].

## Creator voices (unofficial)
<!-- section:creator_voices -->
…

## Community reception
<!-- section:community_reception -->
### Opinion distribution
| source | positive | negative | mixed | neutral | % weighted by likes | sample |
|---|---|---|---|---|---|---|
| YouTube (total) | … | … | … | … | … | 240 comments (relevance) |
| YouTube PL | … |
| YouTube EN | … |
| Steam (polish, 30 d) | … |

### Main themes
Theme → stance [[yt:c:…]].
> "original quote" [[yt:c:…]]
> _(transl.)_ "translation into the report language" [[yt:c:…]]

## Steam
<!-- section:steam -->
…

## Discrepancies and uncertainties
<!-- section:discrepancies -->
…

## Methodology and limitations
<!-- section:methodology -->
_Required section._ Sample size, order=relevance (non-random), no transcripts, heuristic language filter.
```

A Polish report uses Polish headings with the same markers, e.g. `## Informacje oficjalne` + `<!-- section:official -->`,
`## Metodologia i ograniczenia` + `<!-- section:methodology -->`, and the translation label `_(tłum.)_`.

| KEY | Reference heading (EN) | Cited (every paragraph/bullet needs `[[ref]]`) |
|---|---|---|
| `tldr` | TL;DR | yes |
| `findings` | Key findings | yes |
| `official` | Official information | yes |
| `semi_official` | Semi-official information | yes |
| `creator_voices` | Creator voices (unofficial) | yes |
| `community_reception` | Community reception (incl. Main themes; not the distribution table) | yes |
| `steam` | Steam | yes |
| `discrepancies` | Discrepancies and uncertainties | only lines containing numbers (incl. italic notes with numbers) |
| `methodology` | Methodology and limitations | required section |

## Validation rules (`strict=true`)
1. Every paragraph and list item in the cited sections (table above) contains ≥ 1 `[[ref]]`.
2. Every ref exists in the evidence registry (comes from tool results within the last 30 days).
3. Quotes `> …` have a comment/review ref (`yt:c:`, `st:r:`) or a Steam news ref (`st:n:`).
4. No raw URLs outside the registry (`report_save` inserts the links).
5. The `methodology` section exists.

Exceptions: table rows, headings, lines entirely in italics (`_…_`). The sources section is generated by `report_save`
(heading "Sources" for `en`, "Źródła" for `pl`, otherwise "Sources", followed by `<!-- section:sources -->`) — do not write it yourself.
Saved as: `reports/YYYY-MM-DD-<topic_slug>.md` (collision → `-2`, `-3`), with frontmatter containing `query_spec`, the
number of sources and `quota_units`.
